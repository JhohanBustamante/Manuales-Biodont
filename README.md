# Manual de Biodont

Manual de uso del sistema odontológico **Biodont**, para el personal del consultorio:
odontólogos, auxiliares, recepción y administración.

---

## 📖 Cómo abrir el manual

El manual es una página web que funciona **sin internet**, en cualquier computador.

> ⚠️ Si hace clic en `Manual-Biodont.html` aquí en GitHub verá el código, no el manual.
> Para leerlo hay que descargarlo primero. Son tres pasos:

1. Pulse el botón verde **`< > Code`** arriba a la derecha y elija **`Download ZIP`**.
2. Descomprima el archivo que se descarga (doble clic sobre él).
3. Dentro de la carpeta, doble clic en **`Manual-Biodont.html`**. Se abre en su navegador.

Deje la carpeta completa junta: el manual usa las imágenes de `capturas/`, y si se separa el
archivo del resto las capturas no se ven.

### Para tenerlo en PDF

Ábralo y use **Imprimir → Guardar como PDF**. El índice lateral se oculta solo al imprimir.

---

## Qué contiene

El manual está en dos partes:

**Parte 1 — Cómo se hace.** Guías por tarea, de principio a fin:

- Llega un paciente nuevo
- Agendar y reprogramar una cita
- Abrir y llenar la historia clínica
- Registrar una alergia
- Atender y firmar la atención
- Marcar el odontograma
- Cotizar a quien todavía no es paciente
- Presupuesto y aceptación
- Cobrar y cerrar la caja
- Documentos que firma el paciente
- Ver quién entró a qué
- Respaldar la información

**Parte 2 — Referencia.** Para consultar algo suelto: pantalla por pantalla, qué puede hacer
cada rol, qué significa cada estado, qué hacer si algo no funciona, glosario, y un recorrido de
práctica de once pasos para aprender sin miedo a equivocarse.

Tiene **buscador** en la barra lateral: escriba una palabra y filtra las secciones que hablan
de eso, no solo las que la llevan en el título.

---

## Sobre las capturas

Todas las imágenes son del sistema real, tomadas sobre una **base de datos de ejemplo**.

**Los pacientes que aparecen son ficticios** — María Rodríguez, Andrea Salazar, Isabela
Quintero y los demás no existen: los genera el juego de datos de demostración que trae el
sistema para poder practicar. Ninguna captura contiene información de una persona real.
